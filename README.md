# TITFAZ INVESTMENT Pvt Limited website

A responsive HTML, CSS and JavaScript starter portfolio website.

## Files
- `index.html` - page content and structure
- `style.css` - colors, layout, responsive styling
- `script.js` - mobile navigation, project filters and enquiry form demo

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser, or use Visual Studio Code with the Live Server extension.
3. Edit the HTML, CSS and JavaScript files and refresh the browser.

6. The enquiry form opens WhatsApp with a prepared message. Visitors must review and send it in WhatsApp. The website does not store submissions.
7. Confirm contact details and any claims about experience, licences, safety or project results before launch.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new repository, for example `titfaz-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for the deployment to finish. GitHub will show the website URL on the Pages settings screen.

Service photos and Google Fonts are loaded from external services, so an internet connection is required for those assets.
